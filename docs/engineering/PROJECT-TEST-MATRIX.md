## Notes for qualified and non-PASS rows

- **TM-010:** The reusable enforcement base is implemented and tested with a neutral tenant-owned fixture. Every future real Company-owned repository and command must adopt the same permission-bound, SQL-scoped, transactionally revalidated contract and add its own domain-specific tests before that feature can pass.
- **TM-026–TM-029:** The product workflows are not built. Installing fake tests or speculative browser automation would violate the repository's milestone gates.
- **TM-030:** Payment work belongs to Milestone 3 and requires an approved sandbox/provider. It blocks payment readiness only, not the current Phase 1 engineering gate.
- Full browser automation is deliberately not duplicated now. Stable runtime and security behaviour is automated with Node, real Next.js servers, and migrated PGlite; final visible judgement remains in the generated owner handoff.
